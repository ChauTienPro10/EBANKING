# HƯỚNG DẪN CÀI ĐẶT PROJECT MOBILE EBANKING

## Cài đặt Dependencies

###  Cài đặt các thư viện cần thiết

```bash
cd MOBILE/ebanking_mb
npm install
```

###  Cài đặt thêm các thư viện navigation và i18n

```bash
npm install @react-navigation/native @react-navigation/stack
npm install react-native-gesture-handler react-native-safe-area-context react-native-screens
npm install react-native-vector-icons
npm install i18next react-i18next
```

### Cài đặt types cho TypeScript

```bash
npm install --save-dev @types/react-native-vector-icons
```

## Chạy Project

### Khởi động Metro bundler:
```bash
npm start
```

### Chạy trên Android:
```bash
npm run android
```
